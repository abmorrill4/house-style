Rewrite text

Select the paragraphs to rewrite, and then select House Style > Rewrite. To give an instruction, such as shorten to two sentences, select House Style > Ask AI instead.

The arrow next to Rewrite, and the right-click Rewrite item, list Simplify and Shorten. Each one runs without an instruction. A team can change their wording in the FlareAI/prompts folder of the team style guide, in preset-simplify.md and preset-shorten.md.

The AI changes only the wording. It can't change variables, cross-references, snippets, conditions, or formatting, because the AI never gets or writes markup: it gets the text pieces of each paragraph and returns new text for the pieces it changes. The result arrives as word-level tracked changes in one undo step.

Before it applies anything, the plugin checks the AI's result against the style rules. If the rewrite still breaks a rule, the AI gets one more try, with the remaining problems listed.

When the structure must change

Some edits need new structure, such as splitting one step into two or turning a paragraph into a list. When the AI says the instruction needs that, the result window offers Restructure instead…. A restructure returns new markup, which the plugin validates: the plugin rejects anything that drops or changes a variable, cross-reference, snippet, or condition, and nothing changes.

The plugin can reword a paragraph with pending tracked changes, but it can't restructure it. Accept or reject those changes first.
