Rewrite text

Select the paragraphs to rewrite, and then select House Style > Rewrite. To give an instruction, such as shorten to two sentences, select House Style > Ask AI instead.

The arrow next to Rewrite, and the right-click Rewrite item, list Simplify and Shorten. Each one runs without an instruction. A team can change their wording in the FlareAI/prompts folder of the team style guide, in preset-simplify.md and preset-shorten.md.

The AI changes only the wording. It can't change variables, cross-references, snippets, conditions, or formatting, because the AI never gets or writes markup: it gets the text pieces of each paragraph and returns new text for the pieces it changes. The result arrives as word-level tracked changes in one undo step.

Before it applies anything, the plugin checks the AI's result against the style rules. If the rewrite still breaks a rule, the AI gets one more try, with the remaining problems listed.

Write new text

To have the AI write new text, click in a paragraph or heading without selecting anything, and then select House Style > Ask AI. Choose Insert at the cursor, type what the new text should say, and then select Run.

The window shows where the new text goes, the text itself, and what to check. Select Insert to add it to the topic as one tracked change. One Ctrl+Z takes all of it out.

  • The AI uses only facts from the topic, your instruction, and any notes you paste into it. Where it needs a fact it doesn't have, it writes Add details here. so you can fill it in.
  • The new text follows your style guide, and the plugin checks it against the rules before showing it.
  • The plugin lists numbers and names in the new text that aren't in the topic or your instruction, so you can check them.
  • The new text is paragraphs and lists. House Style doesn't insert links, tables, images, variables or snippets. Where the text names the product, it uses the plain name, and House Style Issues then offers to make it a variable.
  • New text goes after a paragraph or heading, not inside a list, table or drop-down.

Talk it through

To ask, refine and then apply, select the text, select House Style > Ask AI, choose Have a conversation, and type your first message. The AI replies with an answer or a suggested change, and you can keep going: "shorter", "keep the word account".

To make a change, choose it under Reply to apply and select Apply. Any suggested change works, an earlier one included, and it goes in as one tracked change that one Ctrl+Z removes. If the text changed since that reply, House Style applies the reply's wording to the text as it is now and tells you so. Each reply shows what it cost.

The conversation ends when you close the window. Nothing in it is saved.

When the structure must change

Some edits need new structure, such as splitting one step into two or turning a paragraph into a list. When the AI says the instruction needs that, the result window offers Restructure instead…. A restructure returns new markup, which the plugin validates: the plugin rejects anything that drops or changes a variable, cross-reference, snippet, or condition, and nothing changes.

The plugin can reword a paragraph with pending tracked changes, but it can't restructure it. Accept or reject those changes first.
