If your team's style guide has owners, only they change its rules. Everyone else sends them a request. House Style does this for you when you aren't listed as an owner, or when you can't write to the guide folder.

## Send a request

1. Select an issue in the issues pane, or a rule in **Rules**.
2. Select **Request Rule Change…** in the pane, or **Request to Disable…**, **Request a Level…** or **Request to Enable…** in **Rules**.
3. Choose **For the whole team…** or **For this project only…**. Under **Set the rule to**, choose Disabled, Suggestion, Warning or Error.
4. Write the **Reason**. The owners need it to decide, so it is required.
5. Select **Send request**.

The rule stays as it is until an owner decides. Its issues show **Request sent**.

To change a rule's wording, select **House Style > My Requests**, select the rule, and then select **Request Rule Change…**. To ask for new rules from a document, select **Import Rules…** there. Style guide owners use **Rule Decisions** instead.

## See the answer

On your next lint after an owner decides, a notice in the pane says whether the request was approved or declined, with the owner's note. An approved project exception is written into your project for you.

To see all your requests and the owners' answers, select **House Style > My Requests**. To take one back, select it and then **Withdraw request**.

## If a request isn't sent

Requests go to the team feedback folder (**Settings > Style guide**). If that folder isn't set or can't be reached, House Style keeps the request and sends it on your next lint. Tell your style guide owner if the folder isn't set.
