---
title: Export for AI assistants
description: Turn your built help into Markdown and an llms.txt file for chatbots and AI assistants.
sidebar:
  order: 6
---

Select **Export for LLMs…** in **House Style > Settings > Advanced** after a build. The plugin turns the built HTML output into one Markdown file per topic, an `llms.txt` index and an `llms-full.txt` file in the output folder, ready for chatbots and AI assistants to read.

To export after every build, select **House Style > Settings**, and on the **Advanced** tab select **After each HTML build, add LLM-ready Markdown and llms.txt to the output**.

**Note:** Trial versions of Flare scramble built output, and the export of a trial build shows the same scrambled text.
