Select **House Style > Write an Introduction** to have the AI write a short introduction for a topic or a section.

## Where it goes

Click in the topic first. House Style writes under the heading above your cursor. If your cursor is above every heading, it uses the topic's first heading. If the topic has no heading, House Style asks you to add one first.

## What it writes

The introduction is two or three sentences in one paragraph, up to 60 words. It says what the topic or section is about. It says who it helps only when the text says so. It doesn't repeat the heading, list every step, or add numbers, steps or settings that the text doesn't give.

A team can change these instructions in the `FlareAI/prompts` folder of the team style guide.

## Check it and insert it

The window works the same as for [Write new text at the cursor](/docs/ai-assists/write-new-text/). It shows where the text goes and the text itself. It also lists numbers and names that aren't in the topic, and style issues the text still has. Select **Insert** to add it as one tracked change, or **Cancel** to leave the topic as it is. Press Ctrl+Z to take the introduction out.

## What it costs

Write an Introduction uses your AI key. See [Models and cost](/docs/settings-and-privacy/models-and-cost/).
