Install House Style

For MadCap Flare 2026 on Windows.

  1. Download

    Get the zip from the latest release.

    Download for Flare 2026

  2. Unblock and extract

    Right-click the zip, select Properties, select Unblock and then OK. Then select Extract All.

  3. Run Install.cmd

    Close Flare, then double-click Install.cmd in the extracted folder.

    Windows asks for administrator approval the first time only.

Start Flare

The House Style tab appears on the ribbon, and a short setup opens.

AI is optional. Lint Topic and Lint Project work without it.

For IT

Install.ps1 -Silent installs with no questions. Install.ps1 -NoAutoUpdate turns updates off. Install.ps1 -Flare 21 installs into another Flare version.

If the tab doesn't appear

  • Select File > Options > Plugins, select House Style and then Enable.
  • Close Flare, run Install.cmd again and restart Flare.

Still stuck? Choose Help > Report a Problem, or open an issue on GitHub.

Uninstall

  1. Close Flare.
  2. As administrator, run
    rmdir "C:\Program Files\MadCap Software\MadCap Flare 22\Flare.app\Plugins\FlareAI"
  3. Delete %LOCALAPPDATA%\HouseStyle.
  4. To remove your settings and key, delete %APPDATA%\FlareAI.
