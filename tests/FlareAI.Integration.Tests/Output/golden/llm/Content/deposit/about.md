# About mobile deposit

Mobile deposit gives members one place to manage each check deposit in Acme Online Banking. You can utilize the check deposit list to confirm the details.

Members can add, change, and remove a check deposit from the **Deposit** page. Each change appears in the account history.

Staff at Acme Financial choose which of these features members see.

Customers who still use the legacy app see a simpler version of this page.
